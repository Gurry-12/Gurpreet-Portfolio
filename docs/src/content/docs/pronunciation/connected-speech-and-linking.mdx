## 1. The 3 Types of Connected Speech

```
1. CONSONANT-TO-VOWEL LINKING (C -> V)
   "Turn it on" is spoken as: "Tur-ni-ton" (/tɜː.nɪ.tɒn/)

2. INTRUSIVE SOUNDS (/w/ and /j/)
   "Go out" becomes "Go-/w/-out"
   "I agree" becomes "I-/j/-agree"

3. ELISION (Disappearing Sounds)
   "Next day" becomes "Nex-day" (the /t/ disappears between consonants)
```
