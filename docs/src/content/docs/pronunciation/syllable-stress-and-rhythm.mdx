## 1. The Core Secret: English is Stress-Timed

- In **Syllable-Timed Languages** (Hindi, Tamil, Spanish), each syllable gets equal duration:
  `ta - ta - ta - ta - ta`
- In **Stress-Timed Languages** (English), only stressed syllables are elongated; unstressed syllables compress rapidly:
  `DAA - duh - DAA - duh - DAA`
