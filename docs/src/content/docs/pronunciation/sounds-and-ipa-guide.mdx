## 1. Why English Spelling is Deceptive

English has **26 letters** but **44 distinct sounds (phonemes)**. This means one letter can represent multiple sounds (e.g. `c` in *cat /k/* vs *city /s/*).

```
                      THE 44 ENGLISH SOUNDS OVERVIEW
  ┌───────────────────────┐  ┌───────────────────────┐  ┌───────────────────────┐
  │   12 PURE VOWELS      │  │     8 DIPHTHONGS      │  │     24 CONSONANTS     │
  │   /iː, ɪ, e, æ, ɑː, ɒ/│  │   /eɪ, aɪ, ɔɪ, aʊ,    │  │   Voiced: /b, d, g, v/│
  │   /ɔː, ʊ, uː, ʌ, ɜː, ə/│ │    əʊ, ɪə, eə, ʊə/    │  │   Voiceless: /p, t, k/│
  └───────────────────────┘  └───────────────────────┘  └───────────────────────┘
```

## 2. Minimal Pairs That Change Meaning

| Sound Pair | Word 1 (Short Vowel) | Word 2 (Long Vowel) | Meaning Difference in Context |
| :--- | :--- | :--- | :--- |
| **/ɪ/ vs /iː/** | **Ship** `/ʃɪp/` | **Sheep** `/ʃiːp/` | *"The container **shipped**"* vs *"The woolly animal"*. |
| **/ɪ/ vs /iː/** | **Fit** `/fɪt/` | **Feet** `/fiːt/` | *"The algorithm **fits**"* vs *"Plural of foot"*. |
| **/æ/ vs /e/** | **Bad** `/bæd/` | **Bed** `/bed/` | Open jaw (/æ/) vs relaxed mouth (/e/). |
| **/p/ vs /b/** | **Pack** `/pæk/` | **Back** `/bæk/` | Voiceless aspirated /p/ vs voiced /b/. |
