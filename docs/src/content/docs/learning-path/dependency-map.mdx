## 2. Cross-Module Dependency Matrix

| Target Module | Depends On (Prerequisites) | Key Bridge Concept |
| :--- | :--- | :--- |
| **Core Java Programming** | Soft Skills, Git | Version control workflow and analytical problem decomposition. |
| **RDBMS & JDBC** | MySQL Database Management | Connecting Java applications to normalized relational schemas. |
| **JSP & Servlets** | Core Java, JavaScript | Request/response lifecycle, HTTP sessions, and MVC web architecture. |
| **Hibernate ORM** | RDBMS & JDBC, Core Java | Object-Relational Mapping, entity lifecycle, and transaction management. |
| **Spring Boot Development** | Spring Core, Spring Framework Basics | Auto-configuration, starter dependencies, and embedded servers. |
| **React Redux State** | React.js Frontend Development | Centralized immutable state management and asynchronous thunks. |
| **Java Microservices** | Spring Boot, Docker | Distributed architecture, service discovery, API gateways, and containerization. |
| **Agentic AI & LangChain** | AI & Machine Learning | LLM prompt engineering, vector databases, and autonomous agents. |
