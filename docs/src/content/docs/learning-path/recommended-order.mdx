This recommended learning order balances prerequisites, cognitive load, and full-stack project building.

## Sequential Phase Execution

<Steps>
1. **I. Foundation** (27.0 Hours)
   - **Milestone:** *Toolchain ready; coding standards & version control habits established.*
   - **Modules:** [Soft Skills & Professional Readiness](/docs/modules/soft-skills-professional-readiness/), [Git & GitHub Version Control](/docs/modules/git-github-version-control/), [Clean Code & TDD](/docs/modules/clean-code-tdd/)
1. **II. Core Programming** (109.5 Hours)
   - **Milestone:** *Proficient in Java OOP; can model systems with SOLID & UML.*
   - **Modules:** [Core Java Programming](/docs/modules/core-java-programming/), [Design Principles (OOPS & SOLID)](/docs/modules/design-principles-oops-solid/), [OOAD & Software Design](/docs/modules/ooad-software-design/)
1. **III. Data & Databases** (17.5 Hours)
   - **Milestone:** *Can design normalized schemas and talk to MySQL from Java (JDBC).*
   - **Modules:** [MySQL Database Management](/docs/modules/mysql-database-management/), [RDBMS & JDBC Connectivity](/docs/modules/rdbms-jdbc-connectivity/)
1. **IV. Web Fundamentals** (44.5 Hours)
   - **Milestone:** *Can build interactive front-ends and Java web apps (Servlets/JSP).*
   - **Modules:** [JavaScript Programming](/docs/modules/javascript-programming/), [Bootstrap Website Design](/docs/modules/bootstrap-website-design/), [JSP & Servlets Web Applications](/docs/modules/jsp-servlets-web-applications/)
1. **V. Persistence & Advanced Java** (47.5 Hours)
   - **Milestone:** *Maps objects to relational data (JPA/Hibernate); concurrency-ready.*
   - **Modules:** [Hibernate ORM Framework](/docs/modules/hibernate-orm-framework/), [Enterprise Java Design](/docs/modules/enterprise-java-design/)
1. **VI. Spring Ecosystem** (28.0 Hours)
   - **Milestone:** *Can build production REST APIs with Spring Boot & Spring MVC.*
   - **Modules:** [Spring Framework Basics](/docs/modules/spring-framework-basics/), [Spring Core Concepts](/docs/modules/spring-core-concepts/), [Spring Boot Application Development](/docs/modules/spring-boot-application-development/), [Spring MVC Web Applications](/docs/modules/spring-mvc-web-applications/)
1. **VII. Frontend Engineering** (42.5 Hours)
   - **Milestone:** *Can build modern SPAs in React with Redux and server-rendered Next.js.*
   - **Modules:** [React.js Frontend Development](/docs/modules/react-js-frontend-development/), [React Redux State Management](/docs/modules/react-redux-state-management/), [Next.js Framework](/docs/modules/next-js-framework/)
1. **VIII. Architecture & Ops** (24.0 Hours)
   - **Milestone:** *Applies GoF patterns; packages apps as Docker containers.*
   - **Modules:** [Design Patterns (GoF)](/docs/modules/design-patterns-gof/), [Docker & Containerization](/docs/modules/docker-containerization/)
1. **IX. Microservices & Mobile** (60.5 Hours)
   - **Milestone:** *Ships Spring Cloud microservices and React Native mobile apps.*
   - **Modules:** [Java Microservices (Spring Cloud)](/docs/modules/java-microservices-spring-cloud/), [React Native Mobile Apps](/docs/modules/react-native-mobile-apps/)
1. **X. Professional & AI** (216.5 Hours)
   - **Milestone:** *Agile/BA fluency; can ship AI/ML and LangChain agent applications.*
   - **Modules:** [Agile Methodology & Scrum](/docs/modules/agile-methodology-scrum/), [Business Analysis](/docs/modules/business-analysis/), [AI & Machine Learning for Software Engineers](/docs/modules/ai-machine-learning-for-software-engineers/), [Agentic AI & LangChain](/docs/modules/agentic-ai-langchain/)
</Steps>

## Weekly Study Pacing Guide

| Study Track | Hours / Week | Total Curriculum Time | Best For |
| :--- | :---: | :---: | :--- |
| **Intensive Bootcamp** | 30h / week | ~20 Weeks (5 Months) | Full-time career changers, intensive students |
| **Standard Professional** | 15h / week | ~41 Weeks (9.5 Months) | Working developers, evening learners |
| **Weekend Self-Paced** | 8h / week | ~77 Weeks (1.5 Years) | Consistent gradual skill builders |
