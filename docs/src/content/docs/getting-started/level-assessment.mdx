## 1. The CEFR Global Language Framework

The **Common European Framework of Reference for Languages (CEFR)** is the global standard for grading language proficiency:

| Level | CEFR Classification | What You Can Do in English | Key Growth Focus |
| :--- | :--- | :--- | :--- |
| **A1** | **Beginner** | Basic greetings, introducing self, simple present questions. | Core vocabulary, basic SVO sentence structure. |
| **A2** | **Elementary** | Simple past narratives, routine daily activities, basic shopping/directions. | Tenses (Simple Past, Present Perfect), common prepositions. |
| **B1** | **Intermediate** | Daily conversations, explaining plans, writing standard workplace emails. | Sentence variety, modals of politeness, phrasal verbs. |
| **B2** | **Upper-Intermediate** | Participating in complex technical discussions, presenting trade-offs, fluent spontaneous conversations. | Advanced conditionals, syllable stress, eliminating L1 regional habits. |
| **C1** | **Advanced** | Effortless fluency, sophisticated vocabulary, negotiating, leading meetings, persuasive writing. | Nuanced idioms, connected speech, executive rhetoric. |
| **C2** | **Mastery** | Native-level precision, spontaneous eloquence in any domain. | Stylistic mastery, cultural depth, public oratory. |

## 2. Self-Evaluation Checklist for Working Professionals

<CardGrid>
  <Card title="Are You at B1 (Intermediate)?" icon="approve-check">
    - Can explain what you worked on yesterday in a standup.
    - Can write a basic support ticket or email request.
    - ⚠️ *Struggles with:* Complex past conditionals, spontaneous interruptions in fast-paced meetings.
  </Card>
  <Card title="Are You at B2 (Professional Working Proficiency)?" icon="star">
    - Can defend an architectural decision or project strategy.
    - Can politely disagree with a colleague during sprint planning.
    - Can give a structured 15-minute presentation with slides.
  </Card>
</CardGrid>
