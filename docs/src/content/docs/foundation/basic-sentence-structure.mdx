## 1. The Subject-Verb-Object (SVO) Rule

Unlike many Indian languages (Hindi, Marathi, Telugu) which follow **Subject-Object-Verb (SOV)** order (*"Maine khana khaya"* \to *I food ate*), English strictly follows **Subject-Verb-Object (SVO)** order.

```
                      ENGLISH VS REGIONAL WORD ORDER

  HINDI / MARATHI (SOV):  [ Subject ]  [ Object ]     [ Verb ]
                          Rahul        the report    submitted.

  ENGLISH (SVO):          [ Subject ]  [ Verb ]       [ Object ]
                          Rahul        submitted     the report.
```

---

## 2. The 4 Fundamental Sentence Patterns

| Pattern | Structure | Example Sentence | Explanation |
| :--- | :--- | :--- | :--- |
| **1. SV** | Subject + Verb | *"The server **crashed**."* | Intransitive verb; requires no direct object. |
| **2. SVO** | Subject + Verb + Direct Object | *"The engineer **wrote** the algorithm."* | Transitive verb; object receives the action. |
| **3. SVC** | Subject + Linking Verb + Complement | *"The application **is** scalable."* | Complement describes or renames the subject. |
| **4. SVOO**| Subject + Verb + Indirect Object + Direct Object | *"The lead **sent** the team an update."* | Indirect object (*the team*) receives direct object (*an update*). |

## 3. Common Sentence Structure Mistakes

<CardGrid>
  <Card title="1. Dropping the Subject (Null-Subject Error)" icon="error">
    - ❌ *Incorrect:* *"Is working properly now."*
    - ✅ *Natural:* *"**It** is working properly now."*
    - **Rule**: English requires an explicit subject pronoun (`it`, `there`, `they`), even for weather or system states (*"It is raining"*, *"There is an error"*).
  </Card>
  <Card title="2. Misplacing Time Adverbs" icon="warning">
    - ❌ *Unnatural:* *"Yesterday I submitted the ticket."* (Acceptable, but placing at end is more neutral).
    - ✅ *Natural:* *"I submitted the ticket **yesterday**."*
    - **Rule**: Standard English places manner, place, and time adverbs at the **end of the clause** (M-P-T order).
  </Card>
</CardGrid>
