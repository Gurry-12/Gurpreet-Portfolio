## 1. Modals Spectrum: Politeness & Degrees of Certainty

```
Certainty:   100% Certain (will, must) ──> 50% Probable (should, ought to) ──> 20% Possible (might, could)
Politeness:  Direct / Commanding (must) ──> Standard (should) ───────────────> Highly Polite (would, could)
```

| Modal | Communicative Purpose | Workplace / Technical Example |
| :--- | :--- | :--- |
| **`Could`** | Polite request / gentle proposal | *"Could you please review PR #89 when you have a moment?"* |
| **`Would`** | Hypothetical suggestion | *"Would it make sense to extract this into a separate helper class?"* |
| **`Might`** | Soft warning of risk | *"This query might cause latency spikes under high concurrent traffic."* |
| **`Should`** | Recommendation / expectation | *"We should add automated integration tests before release."* |
| **`Must`** | Strict regulatory requirement | *"We must comply with data encryption standards."* |
