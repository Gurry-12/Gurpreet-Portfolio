## 1. The 5 Conditionals in Real Life

| Conditional | Form | Real-World Communicative Meaning | Example |
| :--- | :--- | :--- | :--- |
| **Zero** | `If + Present, Present` | Scientific facts, invariant system rules | *"If temperature **rises**, cooling fans **activate** automatically."* |
| **1st** | `If + Present, Will + Verb` | Likely future outcome based on real condition | *"If you **approve** the PR today, I **will deploy** it tomorrow morning."* |
| **2nd** | `If + Past, Would + Verb` | Hypothetical / imaginary current scenario | *"If we **had** more time, we **would refactor** the entire legacy module."* |
| **3rd** | `If + Had V3, Would Have V3`| Regret / Postmortem analysis of past event | *"If the alerts **had triggered**, we **would have resolved** the outage in minutes."* |
| **Mixed** | `If + Had V3, Would + Verb` | Past event affecting present state | *"If we **had implemented** caching last month, our servers **would be** fast today."* |
