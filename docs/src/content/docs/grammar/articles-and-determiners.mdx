## 1. The Definitive Article Rules Matrix

| Noun Category | Article Rule | Natural Examples | Common Error to Avoid |
| :--- | :--- | :--- | :--- |
| **Singular Countable (First mention)** | Use **`A` / `An`** | *"We launched **a** new feature."* | ❌ *"We launched new feature."* (Singular countable MUST have an article!). |
| **Singular Countable (Specific/Known)** | Use **`The`** | *"**The** feature is now live."* | ❌ Missing *the* on second reference. |
| **Plural / Uncountable (General)** | Use **Zero Article \emptyset** | *"\emptyset **Security** is our top priority."* | ❌ *"The security is important."* |
| **Plural / Uncountable (Specific)** | Use **`The`** | *"**The** security of this server is compromised."*| Specific, restricted instance. |
| **Unique Systems / Environments** | Use **`The`** | *"Deployed to **the** cloud / **the** internet / **the** staging server."* | ❌ *"Deployed to internet."* |
