## 1. The QASI Formula for Direct Questions

```
[ Question Word ] + [ Auxiliary Verb ] + [ Subject ] + [ Main Verb (Infinitive) ]
       Why                did                 the server            crash?
       How                does                the cache             work?
       When               will                the team              deploy?
```

---

## 2. Polite Indirect Questions in Meetings

In professional meetings, direct questions (*"Where is the document?"*) can sound demanding. Use **Indirect Questions**:

- ❌ Direct: *"How much will this cost?"*
- ✅ Polite Indirect: *"Could you let me know **how much this will cost**?"* (Notice word order returns to subject + verb!).
- ❌ Direct: *"Did the build pass?"*
- ✅ Polite Indirect: *"Do you happen to know **if the build passed**?"*
