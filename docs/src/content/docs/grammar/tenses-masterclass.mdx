## 1. Overview: The 3 Tense Dimensions

English tenses convey two pieces of information: **Time** (Past, Present, Future) and **Aspect** (Simple, Continuous, Perfect, Perfect Continuous).

```
                      THE 12 TENSES MATRIX IN CONTEXT

               PAST                        PRESENT                     FUTURE
  SIMPLE       I deployed the code.        I deploy code daily.        I will deploy the code.
  CONTINUOUS   I was deploying code.       I am deploying code now.    I will be deploying code.
  PERFECT      I had deployed before QA.   I have deployed the code.   I will have deployed by 5 PM.
  PERF. CONT.  I had been deploying...     I have been deploying...    I will have been deploying...
```

## 2. The Big Three Tense Battles in Daily Communication

<CardGrid>
  <Card title="1. Present Perfect vs Simple Past" icon="random">
    - **Simple Past**: Specific, finished past time (*yesterday, at 3 PM, last week*).
      - *"I **pushed** the changes two hours ago."*
    - **Present Perfect**: Unspecified time, connected to the present result NOW.
      - *"I **have pushed** the changes; you can review the PR now."*
  </Card>
  <Card title="2. Past Continuous vs Simple Past" icon="puzzle">
    - **Past Continuous (`was/were + -ing`)**: Ongoing background action.
    - **Simple Past**: Sudden interrupting event.
      - *"While I **was testing** the endpoint, the server **crashed**."*
  </Card>
  <Card title="3. Will vs Going To vs Present Continuous for Future" icon="rocket">
    - **Will**: Instant decisions / predictions (*"I will check the logs right away"*).
    - **Going To**: Prior intentions / plans (*"We are going to migrate to Java 21"*).
    - **Present Continuous**: Fixed, scheduled arrangements (*"We **are meeting** the client at 4 PM"*).
  </Card>
</CardGrid>
