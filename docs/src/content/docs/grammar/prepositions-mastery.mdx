## 1. The Preposition Pyramid (In, On, At)

```
        IN (General / Broad)
       ┌────────────────────┐   Time: Centuries, Years, Months, Seasons ("in 2026", "in June")
      ┌┴────────────────────┴┐  Place: Countries, Cities, Enclosed Space ("in India", "in memory")
     ┌┴──────────────────────┴┐
    │     ON (More Specific)  │ Time: Days, Dates ("on Monday", "on July 4th")
   ┌┴────────────────────────┴┐Place: Streets, Surfaces, Electronic Media ("on the server", "on Slack")
  ┌┴──────────────────────────┴┐
 │      AT (Very Specific)     │Time: Exact Hours ("at 3:30 PM", "at midnight")
 └─────────────────────────────┘Place: Exact Addresses, Specific Points ("at the office", "at runtime")
```

## 2. Fixed Dependent Prepositions (High-Value Workplace Verbs)

- **Apologize for** (*"I apologize for the delay"*).
- **Approve of** (*"The architect approved of the migration plan"*).
- **Consist of** (*"The architecture consists of three layers"* — NEVER *comprises of*).
- **Depend on** (*"Throughput depends on disk I/O"* — NEVER *depends of*).
- **Focus on** (*"Let's focus on the priority bugs"*).
- **Participate in** (*"I will participate in the sprint retrospective"*).
- **Succeed in** (*"We succeeded in reducing memory consumption"*).
