## 1. Modernizing Stiff Phrasing

| Stiff / Archaic Phrase | Natural Modern Workplace English |
| :--- | :--- |
| *"With reference to the above subject..."* | *"Following up on our conversation about..."* |
| *"Please find attached herewith..."* | *"I've attached the file below."* |
| *"I am writing to intimate you that..."* | *"I wanted to let you know that..."* |
| *"Do the needful at the earliest."* | *"Please review and let me know if you have questions."* |
