## ☕ 1. Core Java, JVM & Concurrency

<CardGrid>
  <Card title="Effective Java (3rd Edition)" icon="open-book">
    **Author**: Joshua Bloch (Former Sun Microsystems Chief Java Architect)
    
    * **Why it matters**: 90 actionable items covering builders, defensive copying, immutability, generics, lambdas, and thread safety.
    * **Key Chapters**: Item 10-14 (Equals & HashCode contract), Item 17 (Immutability), Item 78-84 (Concurrency).
  </Card>

  <Card title="Java Concurrency in Practice" icon="open-book">
    **Author**: Brian Goetz, Tim Peierls, Joshua Bloch, Doug Lea
    
    * **Why it matters**: The definitive authority on the Java Memory Model (JMM), `volatile` semantics, happens-before guarantees, and `java.util.concurrent`.
    * **Key Chapters**: Chapter 3 (Sharing Objects & Visibility), Chapter 16 (Java Memory Model).
  </Card>

  <Card title="The Java Virtual Machine Specification" icon="document">
    **Publisher**: Oracle OpenJDK (Java SE 21 Edition)
    
    * **Official Specification**: [docs.oracle.com/javase/specs/jvms/se21/html/](https://docs.oracle.com/javase/specs/jvms/se21/html/)
    * **Key Sections**: Chapter 2 (Runtime Data Areas, Stack Frames, Method Area), Chapter 5 (Class Loading & Linking), Chapter 6 (Opcode Instruction Set).
  </Card>

  <Card title="Optimizing Java" icon="rocket">
    **Authors**: Benjamin Evans, James Gough, Chris Newland
    
    * **Why it matters**: Mechanical sympathy, JIT compilation tiers (C1 vs C2), bytecode execution, G1/ZGC low-latency collectors.
  </Card>
</CardGrid>

## 🗄️ 2. Databases, Storage Engines & Distributed Systems

<CardGrid>
  <Card title="Designing Data-Intensive Applications (DDIA)" icon="open-book">
    **Author**: Martin Kleppmann (University of Cambridge)
    
    * **Why it matters**: The undisputed bible of modern distributed data systems.
    * **Key Chapters**: Chapter 3 (Storage & Retrieval: B-Trees vs LSM-Trees), Chapter 7 (Transactions & Isolation Levels), Chapter 8-9 (Distributed Consensus & Raft).
  </Card>

  <Card title="Database Internals" icon="open-book">
    **Author**: Alex Petrov
    
    * **Why it matters**: Deep dive into storage engines, page layout, slotted pages, WAL (Write-Ahead Logging), and lock managers.
    * **Essential Reading**: Part 1: Storage Engines (B+ Tree internal node splitting, latch crabbing).
  </Card>

  <Card title="High Performance MySQL (4th Edition)" icon="open-book">
    **Authors**: Silvia Botros & Jeremy Tinley
    
    * **Why it matters**: InnoDB engine mechanics, buffer pool memory allocation, MVCC undo logs, index cardinality, and `EXPLAIN ANALYZE`.
    * **Official Manual**: [MySQL 8.0 InnoDB Reference](https://dev.mysql.com/doc/refman/8.0/en/innodb-storage-engine.html)
  </Card>

  <Card title="Use The Index, Luke!" icon="external">
    **Author**: Markus Winand
    
    * **Free Web Guide**: [use-the-index-luke.com](https://use-the-index-luke.com/)
    * **Why it matters**: Explains how B-Tree index searches work on disk, composite index column order rules, and range predicates.
  </Card>
</CardGrid>

## 💡 How to Read for Maximum Retention

1. **Read with a REPL / Sandbox**: Never read code or specifications passively. Open JShell, a Docker container, or MySQL CLI and immediately test the mechanics described in the text.
2. **Inspect the Bytecode & Query Plans**: When reading about Java or SQL, use `javap -v -c ClassName` and `EXPLAIN FORMAT=JSON SELECT ...` to verify what the compiler and engine actually do.
3. **Build Minimal Reproductions**: If a book describes an architectural trade-off or race condition (e.g. non-repeatable read or deadlock), write a 30-line script to reproduce the exact failure mode.
