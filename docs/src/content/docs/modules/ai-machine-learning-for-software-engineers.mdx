## 1. Module Purpose

Harness Large Language Models (LLMs), Prompt Engineering, Retrieval-Augmented Generation (RAG), Vector Databases, and Agentic Workflows.

---

## 2. Why It Matters for Software Engineering

AI is transforming software engineering from deterministic rule-writing to probabilistic intelligence and autonomous agent workflows.

---

## 3. Learning Objectives

By completing this module, you will be able to:

- Understand LLM tokenization, embeddings, temperature, and context windows.
- Implement production RAG pipelines using LangChain, vector stores, and semantic search.
- Build autonomous agent loops with Tool Calling and memory.
