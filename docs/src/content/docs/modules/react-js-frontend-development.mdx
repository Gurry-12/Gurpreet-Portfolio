## 1. Module Purpose

Build reactive, component-based Single Page Applications using React Hooks, functional components, state management, and virtual DOM diffing.

---

## 2. Why It Matters for Software Engineering

React powers the modern frontend landscape. Proficient state management and render optimization are critical for responsive user experiences.

---

## 3. Learning Objectives

By completing this module, you will be able to:

- Master core hooks: `useState`, `useEffect`, `useMemo`, `useCallback`, and `useRef`.
- Manage global application state cleanly using Redux Toolkit or React Context.
- Optimize rendering: avoid unnecessary re-renders using proper memoization.

## 12. Common Mistakes & Anti-Patterns

Avoid these common React engineering mistakes:

- ⚠️ **Using Array Index as Key**: Causes subtle state bugs and unnecessary re-renders when list elements are reordered, inserted, or removed. Always use persistent unique IDs.
- ⚠️ **Direct State Mutation**: Mutating state objects directly (`state.user.name = 'Bob'`) bypasses React's `Object.is` shallow equality check, failing to trigger re-renders.
- ⚠️ **Omission of Dependencies in `useEffect`**: Omitting reactive props or state from dependency arrays creates stale closures holding obsolete values.
- ⚠️ **Unnecessary State Synchronization**: Deriving state from props using `useEffect` + `setState` introduces extra render cycles and race conditions. Compute values on the fly during render.

---

## 13. Interview Relevance

Expect the following React architecture interview dimensions:

- 💡 **Fiber Reconciliation**: How does the Fiber linked-list tree allow React to pause and resume rendering work?
- 💡 **Render Phase vs Commit Phase**: Which lifecycle phase is asynchronous and pure? Why must side-effects never run during the render phase?
- 💡 **Hooks Implementation Model**: How does React track hook state across render cycles using a singly-linked list on the Fiber node?
