## 1. Module Purpose

Build deep, idiomatic proficiency in Core Java, including OOP fundamentals, memory management, JVM architecture, Generics, and Collections.

---

## 2. Why It Matters for Software Engineering

Java powers global enterprise backends. Understanding object lifecycle, heap/stack memory, and standard library collections prevents subtle production bugs.

---

## 3. Learning Objectives

By completing this module, you will be able to:

- Master JVM memory model: Stack vs Heap, Garbage Collection algorithms, and class loading.
- Leverage the Collections Framework (List, Set, Map, Queue) with proper algorithmic Big-O selection.
- Apply Streams, Lambdas, and Modern Java (Java 8–17+) idiomatically.

## 12. Common Mistakes & Anti-Patterns

Avoid these critical production mistakes frequently encountered in enterprise Java systems:

- ⚠️ **Using `==` instead of `.equals()` for String & Wrapper Comparison**: `==` checks reference identity. For cached strings or autoboxed integers between -128 and 127, `==` may appear to work in tests but causes catastrophic silent failures in production.
- ⚠️ **Resource Leaks from Unclosed Streams & Connections**: Failing to use `try-with-resources` (`AutoCloseable`) on JDBC connections, file streams, and sockets leads to file descriptor exhaustion and database connection pool starvation.
- ⚠️ **Mutating Objects Used as HashMap Keys**: Mutating an object after storing it in a `HashMap` alters its `hashCode()`, making the key unretrievable and causing silent memory leaks.
- ⚠️ **Catching `Throwable` or `Exception` Broadly**: Swallowing root exceptions hides fatal `VirtualMachineError` or `OutOfMemoryError` conditions, leaving the application in an indeterminate zombie state.
- ⚠️ **Ignoring Volatile Compound Atomicity**: Assuming `volatile int count; count++` is thread-safe; `count++` is a 3-step non-atomic operation that drops updates under concurrency.

## 13. Interview Relevance

Expect the following deep technical interview dimensions for Core Java:

- 💡 **JVM Memory & Garbage Collection**: Explain the difference between Eden, Survivor, and Tenured spaces. How do G1 GC and ZGC minimize stop-the-world pause times?
- 💡 **HashMap Collision Resolution**: Walk through the step-by-step lifecycle of `put(K, V)`. When does a bucket convert to a Red-Black Tree, and why is `(n - 1) & hash` used instead of `%`?
- 💡 **Java Memory Model**: What is the happens-before relationship? Why does `Double-Checked Locking` require the `volatile` keyword?
- 💡 **Generics Variance**: Explain the PECS rule (`Producer Extends, Consumer Super`). Why are Java arrays covariant while generic lists are invariant?
