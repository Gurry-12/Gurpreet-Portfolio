## 1. Module Purpose

Master distributed version control, branching workflows, pull requests, rebase vs merge, and collaborative engineering standards.

---

## 2. Why It Matters for Software Engineering

Version control is the lifeblood of software teams. Sloppy Git habits lead to lost code, broken deployments, and merge conflicts that paralyze releases.

---

## 3. Learning Objectives

By completing this module, you will be able to:

- Execute three-way merges, interactive rebases, and conflict resolution confidently.
- Enforce branch protection, semantic commit conventions, and GitHub PR reviews.
- Diagnose repository history using git log, reflog, bisect, and cherry-pick.

## 10. Practical Exercises & Real-World Projects

:::note Educational Guidance
Apply the knowledge from this module with concrete engineering projects:
:::

<Steps>
1. **Conflict Simulator**: Create two branches modifying the same lines, perform a merge, and manually resolve conflicts using Git CLI.
1. **Interactive Rebase Drill**: Squash 5 messy commits into a single clean conventional commit (`feat: ...`).
1. **Recovery Drill**: Recover a deleted commit using `git reflog`.
</Steps>

## 12. Common Mistakes & Anti-Patterns

Avoid these common traps frequently encountered by junior and mid-level developers:

- ⚠️ **Skipping fundamentals and jumping straight into high-level abstractions.**
- ⚠️ **Ignoring error states, nullability, and resource leaks.**
- ⚠️ **Failing to profile performance under realistic concurrency or data volume.**
