## 1. Module Purpose

Master the Spring Framework, Inversion of Control (IoC), Dependency Injection (DI), Spring Boot autoconfiguration, and RESTful API development.

---

## 2. Why It Matters for Software Engineering

Spring Boot is the de-facto standard for enterprise Java microservices and web backends, drastically reducing boilerplate.

---

## 3. Learning Objectives

By completing this module, you will be able to:

- Understand the Spring ApplicationContext, Bean lifecycle, and `@Component`/`@Autowired` injection.
- Build production-grade REST APIs with Spring MVC, `@RestController`, and validation.
- Configure Spring Boot profiles, Actuator health endpoints, and externalized properties.

## 12. Common Mistakes & Anti-Patterns

Avoid these critical Spring Boot production traps:

- ⚠️ **Field Injection (`@Autowired` on Private Fields)**: Makes unit testing difficult without starting an entire Spring context, hides tight coupling, and prevents creating immutable components. Always use **Constructor Injection**.
- ⚠️ **The Self-Invocation `@Transactional` Bypass**: Calling a `@Transactional` method from within the same class (`this.method()`) bypasses the Spring AOP dynamic proxy, resulting in zero transaction demarcation.
- ⚠️ **Executing Blocking Remote Calls Inside Transaction Boundaries**: Holding a database connection open while making slow external HTTP/RPC requests causes connection pool starvation across the entire application.
- ⚠️ **Disabling Spring Security CSRF Without Token Guards**: Blindly adding `.csrf(AbstractHttpConfigurer::disable)` on browser-based cookie session apps opens vulnerability to Cross-Site Request Forgery attacks.

## 13. Interview Relevance

Expect the following deep technical questions in Spring engineering interviews:

- 💡 **Auto-Configuration Engine**: How does `@EnableAutoConfiguration` discover configuration classes? Explain the role of `@ConditionalOnMissingBean`.
- 💡 **Bean Lifecycle Phases**: Walk through the lifecycle from `BeanDefinition` creation, instantiation, property population, `BeanPostProcessor` before/after hooks, to initialization.
- 💡 **Transaction Propagation**: What is the difference between `REQUIRED` and `REQUIRES_NEW`? Why do checked exceptions not trigger a rollback by default?
- 💡 **Circular Dependency Resolution**: How does Spring's 3-level singleton cache resolve circular dependencies in setter injection?
