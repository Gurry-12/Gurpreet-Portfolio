## 1. Top Workplace Idioms

- **On the same page**: Having a shared understanding (*"Let's sync up to make sure we're on the same page."*)
- **Touch base**: Briefly connect or communicate with someone (*"I'll touch base with you after the client call."*)
- **Ballpark figure**: An approximate estimate (*"Could you give me a ballpark figure for the cloud migration cost?"*)
- **Hit the ground running**: Start an activity immediately with full energy (*"The new team lead hit the ground running."*)
- **Low-hanging fruit**: Simple, easy-to-achieve improvements (*"Fixing CSS alignment is low-hanging fruit."*)
- **Back to the drawing board**: Start over after an idea fails (*"The prototype failed performance tests, so it's back to the drawing board."*)
