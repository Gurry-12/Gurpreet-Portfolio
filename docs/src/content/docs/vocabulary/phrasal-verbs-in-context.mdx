## 1. Workplace & Project Phrasal Verbs

| Phrasal Verb | Meaning | Natural Example |
| :--- | :--- | :--- |
| **Kick off** | Start a project or initiative | *"We **kicked off** the migration sprint this morning."* |
| **Wrap up** | Finish or conclude an activity | *"Let's **wrap up** this meeting in the next five minutes."* |
| **Follow up on**| Check the progress of a previous item | *"I will **follow up on** the ticket with the infrastructure team."* |
| **Call off** | Cancel a scheduled event | *"The client **called off** the afternoon sync due to a conflicting meeting."* |
| **Put off** | Postpone / delay | *"We cannot **put off** this database upgrade any longer."* |
| **Run into** | Encounter unexpected difficulties | *"We **ran into** some permission issues during deployment."* |
| **Look into** | Investigate a problem | *"I will **look into** the logs and report back by 2 PM."* |
| **Sort out** | Organize and resolve a messy situation | *"We spent the morning **sorting out** the merge conflicts."* |
