## 1. The Signposting Phrase Toolbox

| Conversational Goal | Signposting Phrase | Example Sentence |
| :--- | :--- | :--- |
| **Structuring a Complex Answer**| *"I'd like to break this down into three parts..."* | *"Let me break this down into architecture, testing, and deployment."* |
| **Adding a Counterpoint** | *"Having said that, we must also consider..."* | *"Having said that, we must also consider latency implications."* |
| **Returning to the Main Topic** | *"Coming back to the main point..."* | *"Coming back to the original question, the release is on schedule."* |
| **Summarizing Key Takeaway** | *"The key takeaway here is that..."* | *"The key takeaway is that automated tests prevent 90% of regressions."* |
