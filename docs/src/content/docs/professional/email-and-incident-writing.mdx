## 1. High-Impact Email Structure

```text
Subject: [Action Required] Approval for Database Migration - Sprint 42

Hi Team,

I hope you're having a productive week.

**Summary:**
We have scheduled the MySQL database index migration for Thursday at 22:00 UTC.

**Expected Impact:**
- Zero downtime expected; read traffic will be routed to the replica.
- Migration duration: ~15 minutes.

**Next Steps:**
Please let me know if you have any conflicting release schedules before Wednesday 17:00 UTC.

Best regards,
Amit Sharma
```
