Background

Who I Am

A compact bio — where I come from and what I build today.

I'm a Computer Science graduate from Gulzar College of Engineering, Punjab Technical University, specializing in IoT, Cyber Security, and Blockchain. Currently contributing as a Software Engineer at Monocept, where I build Java and Spring Boot backend services with role-based JWT auth, relational schema design, and clean API contracts.

Before that, I interned at Anviam Solutions building ASP.NET Core APIs, Python backend modules, and SQL query optimizations; and at Codehop Interfusion building test-driven utilities with Python, Flask, and BDD testing pipelines.

I also served as Chairperson of CodeForge — a student developer community — organizing coding competitions, hackathons, and peer-learning workshops. Explaining complex systems to others is how I verified that I actually understood them.
